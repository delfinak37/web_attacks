# Внедрение кода (Injection)

### Цель работы

Выявить наличие уязвимостей внедрения кода в веб-приложении, проанализировать возможность выполнения несанкционированных запросов к базе данных или исполнения произвольного кода на стороне сервера. 
Определить векторы атаки и оценить потенциальный ущерб от успешной эксплуатации.

## Ход выполнения

### 1) Разведка

В ходе анализа функционала веб-приложения был обнаружен эндпоинт, связанный с отображением продуктов: `GET /api/products/views`. Предположительно, данный эндпоинт взаимодействует с базой данных для учета просмотров. 
Для передачи имени продукта используется заголовок `x-product-name`.

<img width="604" height="472" alt="изображение" src="https://github.com/user-attachments/assets/71de3e3b-d453-4d57-9efb-403432d84aad" />

### 2) Атака

Для проверки наличия SQL-инъекции в заголовок `x-product-name` было внедрено специальное значение, содержащее одинарную кавычку - символ, используемый в SQL-запросах для обозначения границ строки. 
Внедрение кавычки нарушает структуру запроса и может вызвать ошибку интерпретации на стороне сервера.

С помощью Burp Suite в эндпоинт `GET /api/products/views` был отправлен запрос со значением `Opal'` в заголовке `x-product-name`:

<img width="603" height="482" alt="изображение" src="https://github.com/user-attachments/assets/db4caf40-926a-41a5-908c-5cff638c2044" />

### 3) Эксплуатация

В ответ на запрос сервер вернул сообщение об ошибке, которое подтвердило наличие уязвимости и раскрыло дополнительную информацию о системе.

**Ответ сервера:**

<img width="615" height="220" alt="изображение" src="https://github.com/user-attachments/assets/c5f34c33-4b26-4ee0-b97f-a40582ec1b13" />

Анализ полученных данных:
  - Подтверждение SQL-инъекции: Текст ошибки показывает, что переданное значение `Opal'` было напрямую подставлено в SQL-запрос.
Лишняя кавычка привела к синтаксической ошибке. Это классический признак уязвимости, позволяющий модифицировать логику исходного запроса 

  - Раскрытие структуры приложения: В поле location сервер вернул абсолютный путь к файлу-обработчику на сервере.
Такая информация не должна быть доступна извне, так как помогает атакующему понять внутреннюю структуру приложения.

Для подтверждения уязвимости был отправлен запрос с корректным значением `Opal` (без кавычки) - ошибка отсутствовала:

## Выводы о защищенности

В результате анализа выявлена уязвимость класса SQL-инъекция в эндпоинте `/api/products/views`. 
Отсутствие фильтрации входных данных в заголовке `x-product-name` позволяет нарушить структуру SQL-запроса, что подтверждается ошибкой при внедрении одинарной кавычки. 
Успешная эксплуатация привела к раскрытию внутренней структуры приложения через поле `location` с абсолютным путем к файлу на сервере. 
Данная атака классифицируется как **CWE-89: Improper Neutralization of Special Elements used in an SQL Command ('SQL Injection')**.
