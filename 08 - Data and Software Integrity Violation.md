# Нарушение целостности данных и программного обеспечения (Data and Software Integrity Violation)

### Цель работы

Выявить возможности вмешательства в целостность данных и программного обеспечения веб-приложения. Проэксплуатировать способы подмены, модификации или внедрения вредоносного кода через уязвимости в серверном или клиентском ПО.

## Ход выполнения

### 1) Разведка

В качестве испытуемого был развернут докер с сайтом `owasp-juice.shop`. Переходя сразу к делу, в ходе взаимодействия с сайтом было установлено, что при добавлении товара в корзину происходит отправка HTTP-запроса к серверу. Ниже перехваченный запрос:


```http
POST /api/BasketItems/ HTTP/1.1
Host: localhost:3000

...

{
  "ProductId":25,
  "BasketId":"6",
  "quantity":1
}
```
