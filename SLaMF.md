# Ошибки логирования и сбои мониторинга (Security Logging and Monitoring Failures)

### Цель работы

Проанализировать механизмы логирования и мониторинга в веб-приложении на предмет их эффективности при обнаружении атак. 
Выявить недостатки в регистрации событий безопасности, отсутствие алертов и реакций на подозрительную активность, а также оценить 
возможность длительного нахождения злоумышленника в системе без обнаружения.

## Ход выполнения

### 1) Разведка

Для анализа был выбран модуль Command Injection в DVWA. Данный модуль позволяет выполнять системные команды через уязвимый параметр, что оставляет следы в логах веб-сервера.
Для доступа к логам был использован запущенный Docker-контейнер с DVWA. Логи Apache внутри контейнера находились по стандартному пути:

### 2) Атака

Для проверки эффективности мониторинга была проведена атака: в поле ввода IP-адреса был отправлен следующий payload:

```bash
127.0.0.1 && cat /etc/passwd
```
