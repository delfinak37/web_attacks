# Бесконтрольная загрузка файлов (Unrestricted File Upload)

### Цель работы

Выявить возможность загрузки и выполнения вредоносных файлов на сервере, проанализировать механизмы проверки загружаемых файлов
и оценить риск компрометации сервера через неконтролируемую загрузку.

## Выводы о защищенности

В результате анализа выявлено отсутствие механизмов проверки загружаемых файлов: не контролируется тип файла, не проверяется его содержимое, файлы загружаются
в доступную директорию и могут быть выполнены на сервере. Это позволяет злоумышленнику загрузить вредоносный скрипт и получить удаленный доступ к системе.

Данная атака классифицируется как:

- CWE-434: Unrestricted Upload of File with Dangerous Type - неограниченная загрузка файлов опасного типа

- CWE-94: Improper Control of Generation of Code ('Code Injection') - возможность выполнения загруженного кода на сервер
